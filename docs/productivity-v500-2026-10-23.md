## 数据与权限设计

旧表采用增加字段和独立扩展表的方式迁移。所有旧插入路径都会生成稳定编号；未排期任务安排截止日期时保留身份。各功能查询按账号隔离，包括没有登录编号的本地测试账号。

完整备份包含本机所有账号数据库和应用持久附件，包含个人数据；不会上传。恢复只接受已校验的备份格式，拒绝路径穿越、Windows 路径别名和链接目录。恢复失败时保留原数据并显示错误；发生自动回退失败则停止启动并说明备份位置。日程交换文件不是完整备份，不包含附件、作品、专注、习惯、登录资料或密钥。

全局撤回只逆转记录的变更，遇到后续修改或身份冲突会停止；不会整库回滚覆盖新数据。专注记录和习惯各有独立撤回与回收方式。同步操作保留独立审计，清单共享使用有期限、可撤销的随机凭据；保存的是令牌哈希。API/WebDAV 密钥由当前 Windows 登录加密。

## 验证与交付

验证使用 `.cache` 下的隔离数据库和临时本机服务。真实用户数据仅在最终升级时保留、备份和复制验证；不向外部服务发送用户任务。

最终完整 Python 回归 254 项通过，覆盖迁移、账号隔离、任务树、时钟、时段分配、重复请求、冲突回滚、备份损坏、恢复失败、撤回、导出与页面集成。月历适配 192 种组合、专注前端时钟与 600 种布局检查、全部前端 JavaScript 语法检查通过。

PyInstaller 构建成功，实际 EXE 在移除外部 Python 环境并禁止 Python TCP 监听的条件下通过启动、注册、重启保留账号与日程、多级已完成任务树和内置离线 OCR 验证。桌面页面来源为 `https://ddl.invalid`。

浏览器实测包括未排期任务创建及清单、筛选、Ctrl+K 搜索定位、无需作品计时、任务时长关联、历史编辑、习惯打卡、备份创建和右侧栏留位。新增日历与连接功能分别在临时环境验证，截图保存在 `docs/images`。

## 使用边界

- 本次发布提供 Windows x64 安装包、便携 ZIP 与 SHA-256 校验文件；本地测试结果不代表已在每种设备及第三方服务上完成验证。
- 手机入口为局域网网页，需要电脑保持运行且设备互通。默认不监听网络端口；启用共享后才创建独立服务。没有部署互联网服务器或原生手机 App。
- WebDAV 需要已有 HTTPS 服务账号，必须支持 ETag 条件写入。AI 需要用户自己的兼容接口、模型和密钥。接口失败、重定向、远端并发变化都会停止操作；真实第三方服务本次未使用个人凭据验收。
- 语音是否可用取决于系统/浏览器，可能调用系统或浏览器的语音服务；不宣称离线语音识别。无兼容 API 时提供 Windows `Win + H` 操作指引。
- 月历保持整月适配，过多事项仍在日期格内展开滚动。年视图用于全年概览，细节通过日期进入日视图；导出图默认隐藏具体任务名称。
- 无法从现有数据复现的历史丢档、数字串标题等问题，不声称已经证实根因并修复；本次增加稳定编号、恢复和一致性检查降低再次发生时的损失。
