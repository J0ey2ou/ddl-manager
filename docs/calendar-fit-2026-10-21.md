# v4.4.2 日历整月自适应验证记录

更新日期：2026-10-21。

## 改动

月历使用窗口内实际可用宽高计算统一缩放比例，标题、日期、事项文字及按钮同步缩放。四、五、六行月份均可在当前页面完整显示。每天预览两条事项，更多事项在该日期格内展开和滚动，不再推高整个月份。修正缩放后的拖拽预览尺寸与指针位置。

![1366×768 窗口中的整月日历](images/calendar-fit-1366x768.jpg)

## 验证

- 150 项 Python 回归测试通过，覆盖任务、日历、账号隔离、专注、提醒和离线识别等现有功能。
- `tests/test_calendar_fit.js` 验证 192 组窗口尺寸与月份行数组合，以及无效尺寸输入。
- 专注前端回归测试及两个改动 JavaScript 文件的语法检查通过。
- 浏览器验证 1366×768 下四、五、六行月份，以及 1024×600、1920×1080 下六行月份；整月可见，页面无额外纵向溢出。
- 验证密集日期的展开、格内滚动、最后一项编辑，以及从 11 月 2 日拖到 11 月 3 日并保存日期；拖拽结束无残留预览。
- 浏览器测试使用隔离数据库与示例任务；不会修改使用者原有数据。

这里记录已完成的回归及浏览器检查。窗口极小时文字会随日历缩小，属于等比例适配的结果。年历、日周视图及仪表盘图片导出不包含在本次月历修复中。此前用户反馈的其他修复与边界见 [v4.4.1 记录](user-feedback-review-2026-10-19.md)。
