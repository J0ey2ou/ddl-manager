# DDL Manager · 我的 DDL

**简体中文** | [English](README_EN.md)

## 版本与运行要求

- **当前版本：v4.3.0 · 专注与作品集**。
- **系统：Windows 10 2004 或更新版本 / Windows 11**
- **架构：64 位 x64**
- **运行组件：Microsoft WebView2**，推荐安装包已内置完整离线安装器，无需单独下载；便携版需要电脑已有 WebView2。
- **安装位置：C 盘、D 盘、E 盘等可写目录均可。**

## 新增：专注与作品集

打开顶部“专注”，先创建房屋、农田或拼图作品，并设置完成它需要的成功次数（1–200 次）。选择 1–180 分钟的时长，开始专注；倒计时结束会自动保存一次成功。

- **房屋搭建**：一次成功添一块砖，完成后呈现完整小屋。
- **小小农田**：每次开始前可从 20 种植物中选择一株，成功后播种，带有生长和轻摇动画。
- **记忆拼图**：导入本机 JPG / PNG / WebP 图片（最大 10 MB、2400 万像素），按目标次数切分；每次成功嵌入一块，从灰色恢复图片原色。
- **悬浮专注**：右键悬浮窗 →“专注计时”，设置时长并开始；“打开专注作品集”进入完整页面。支持倒计时、进度条、C4 倒计时与结束特效，主页面和悬浮窗同步暂停、继续及结束。
- **保存规则**：成功和作品按本地账号保存；每轮只归属一件作品，目标创建后固定。暂停不结算，提前结束不计成功；关闭页面后继续计时，软件退出或电脑休眠后，下次打开按结束时间结算。
- **功能开关**：设置 → 窗口管理 →“专注（房屋 / 农田 / 拼图）”。关闭后隐藏专注页面及右键入口，结束所有账号尚未完成的计时；已有作品、导入图片和成功记录保留。

图片和专注记录保存在本机数据库中，不上传云端，不包含在“导出日程”的文件里。

## 新增：免费本地智能提醒

打开顶部“智能提醒”页，按截止时间查看近期逾期和未来七天事项。DDL 默认提前 60 分钟，独立日程在开始前 15 分钟提醒；已完成和已删除的事项停止提醒。

- 设置 → 本地智能提醒：默认开启，可调整提前时间（0 表示到期时提醒），默认 22:00–08:00 静默；点击“测试桌面提醒”验证 Windows 通知。
- 支持稍后 15 分钟、1 小时或 24 小时提醒，及本次不再提醒；忽略只影响当前截止日期，改期或新一轮重复事项可再次提醒。
- 同批提醒合并展示，每个阶段持久去重；后台托盘运行时有效，软件完全退出或电脑关闭时不提醒。静默结束或恢复运行后，仅补发最近七天仍未完成的事项；更早逾期只在列表显示。
- 使用本地规则，无需 AI API、Tunnel、网络或额外服务。Windows 通知/勿扰设置会影响是否看到弹窗。

智能提醒页提供“一键复制给 ChatGPT”：生成当前账号的日程文字，手动粘贴到 ChatGPT 获取优先级与执行建议。把需要新增的建议复制回文字识别窗口，预览后添加。这是手动往返，不是自动同步；ChatGPT 使用你自己的账号和现有额度，DDL 不会发起 AI 请求。

## 可选：ChatGPT / Dot 本机连接（预览）

在设置中开启后，Dot 可通过自定义 MCP 插件查询、新增、改期、完成和删除日程，并订阅事项变化与到期提醒。双向操作同一份本机数据，支持撤回、重试去重和修改冲突检查。电脑、DDL 和官方 Tunnel 连接程序必须保持运行。

**需要自行连接插件、配置 Tunnel 并订阅提醒；打开开关不等于已连接 Dot。真实 Dot 账号的通知链路尚未完成端到端验证。** 详见 [连接步骤与运行边界](DOT_SETUP.md)。

## 功能说明

把每天的安排、课程和截止事项放在一起：在主页看清先做什么，在日历中安排日期，在今日时间轴中规划一天，也能通过桌面悬浮窗随时查看进度。支持本地文字与图片识别、完成统计、跨电脑日程文件同步及 Microsoft To Do 同步。

### 1. 日程与待办管理

- **截止日期管理**：为事项设置名称、日期与时间，通过剩余时间、颜色和进度条判断紧迫程度。
- **主页集中查看**：按截止时间排列待办，同时显示所有未完成的独立日程（包括今天、未来和已逾期的日程）。
- **分类管理**：自动识别常见类别，也可自定义分类、选择多个分类并筛选查看。
- **父子任务**：把大任务拆成多个子任务，查看完成数量与小进度；子任务截止时间不能晚于父任务。
- **重复事项**：支持每天、每周、每月重复安排。
- **快捷设定时间**：通过“今晚、明天、周末、下周”等选项快速填写截止时间。
- **日常操作**：编辑、删除、完成和恢复未完成；DDL 待办支持批量完成、删除及修改分类。

### 2. 文字、图片与课表识别

- **中文文字拆分**：识别一段文字中的多条事项、日期、常见时段、编号列表及共享日期。
- **图片 OCR**：选择或粘贴图片，在本地识别文字并生成事项预览。
- **课表导入**：按学期第一周日期、星期、时段和周次预览、调整，再批量加入日程。
- **确认后加入**：可以在预览中修改名称、时间和事项类型，勾选后加入；下方列表立即更新。
- **剪贴板快速入口**：在其他软件复制文字或图片后，通过快捷键、托盘菜单或悬浮窗菜单打开独立识别小窗。

例如输入：

```text
明天下午完成三件事：1.整理资料；2.准备演示；3.检查清单
```

软件会拆分事项并共用对应日期与时段。识别结果可修改，建议核对后再加入。文字规则与 OCR 模型随软件提供，无需 AI API，图片识别不上传云端。

### 3. 日历与拖动排期

- 月历整合 DDL 待办和日程，关联条目去重展示。
- 每个日期格默认容纳 **3 条事项**，保持一致高度；点击“还有 N 项”展开，再次点击收起。
- 按住事项拖到其他日期即可改期，保留原有时间，页面保持原来的滚动位置。
- 拖动时任务条跟随鼠标移动，改期成功后主页同步更新。
- 支持分类筛选、切换月份和回到本月。
- 点击待办进行编辑，点击日程进入对应日期；日期格显示完成数量和节日信息。

### 4. 今日安排与时间轴

- 按日期集中查看当天日程、计划块和到期待办。
- 为计划设置开始时间、结束时间和备注，在时间轴上查看一天的安排。
- 支持手动添加，也可通过“快速拆分今日事项”批量生成安排。
- 支持编辑、完成、恢复未完成和删除，并与主页、日历及统计联动。

### 5. 完成记录与进度统计

- 区分未完成、已完成、逾期未完成、按时完成和逾期完成。
- 使用 `✓` 标记按时完成，使用 `!` 标记逾期完成，也可为过去的事项补记完成状态。
- 查看制定数量、完成数量、完成率、准时率、逾期数量及效率评分。
- 支持年度月度对比、月份对比、分类统计和大任务进度。
- 完成热力图按实际完成日期展示；统计包含独立日程，并对与 DDL 关联的日程去重。

### 6. 跨电脑同步日程

主页右下角、撤回按钮上方提供 **导出日程** 和 **导入日程**，首次点击会显示简短说明。

1. 在电脑 A 登录本地账号，点击“导出日程”，保存 `.ddl.json` 文档。
2. 通过 U 盘或您选择的方式把文件复制到电脑 B。
3. 在电脑 B 安装本软件并登录本地账号，点击“导入日程”，选择该文件。
4. 查看新增和匹配数量；遇到分类冲突时，选择“保留原有分类”或“采用导入分类”，再确认导入。

**同步规则：**

- **名称与日期相同**：同步文件中的完成状态和完成时间，包括按时完成、逾期完成及恢复未完成；名称比较时忽略首尾空格。
- **其余事项**：直接添加，本机独有事项仍然保留。
- **分类不一致**：弹窗逐项选择，不会未经确认覆盖。
- **重复导入**：同一文件不会重复添加；同名同日有多条时，优先匹配相同类型和具体时间，再逐条匹配。
- **内容保留**：已有事项保留本机时间、备注和类型；新增事项携带原文件中的分类、备注、重复设置、历史记录及有效父子关联，关联计划随 DDL 一同传递。本机父任务截止时间较早时，新子任务作为独立事项保留。
- **操作可撤回**：确认后立即更新主页，可通过“撤回：导入日程”撤销整次操作；取消预览不会修改事项。

导出范围为当前账号的日程，不包含登录信息或软件设置。此功能通过文件手动同步，不会自动联网；单个文件最大 10 MB，支持最多 10000 条事项及 10000 条关联计划。

### 7. 桌面悬浮窗

- 显示未完成事项，每页最多三条，支持翻页。
- 显示标题、剩余或逾期时间和进度条；`✓` 按时完成、`!` 逾期完成、`×` 删除。
- 拖动标题或文字区域移动窗口，`＋` 打开独立快速添加窗口。
- 靠左侧、右侧或顶部放置后，鼠标移开自动收起，点击细小呼出条恢复。
- 右键可呼出主界面、打开设置、从剪贴板添加日程或退出；操作其他窗口后菜单自动关闭。
- 支持置顶、大小和不透明度调整，滑块修改可实时预览。

### 8. Microsoft To Do 同步

在设置中主动登录微软账号后，可以将本地事项**单向同步**到 Microsoft To Do，默认使用 `DDL Manager` 清单。

- 支持手动同步及可选自动同步。
- 同步本地新增、修改与完成状态，通过来源关联减少重复上传。
- 显示登录账号、目标清单和云端确认状态；不删除云端任务。
- 首次同步不上传已完成的历史事项；微软登录在本次运行内有效，退出后需重新授权。

此功能需要联网，微软端的修改不会反向同步到本软件，不影响其他功能离线使用。

### 9. 撤回、快捷键与后台运行

- **撤回**：本次运行中保留当前账号最近 30 次可撤回操作，包括日程文件导入；隐藏到托盘不会清空，完全退出后清空。
- **系统托盘**：点击主窗口 `X` 隐藏到 Windows 托盘；悬浮窗单独运行时不占用任务栏。双击托盘图标恢复主界面，右键“呼出悬浮窗”可开启或恢复悬浮窗，选择“退出程序”完全退出。
- **开机启动**：可在设置中开启，登录 Windows 后进入托盘。
- **单实例运行**：再次双击软件会唤回已有窗口。
- **本地账号**：支持注册、登录及切换账号。
- **全局快捷键**：可在设置中自行修改。

| 默认快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + A` | 打开主页添加事项 |
| `Ctrl + Alt + C` | 打开日历 |
| `Ctrl + Alt + T` | 打开今日事项 |
| `Ctrl + Alt + D` | 显示或隐藏主窗口 |
| `Ctrl + Alt + V` | 从剪贴板打开独立快速识别窗口 |

### 10. 外观与个性化

- 多种背景主题与紧迫度配色模式，包括固定阈值、动态范围和混合模式。
- 可调整名言内容、显示开关和页面模块。
- 支持中英文界面选项。
- 悬浮窗大小、透明度和置顶状态可按需要设置。
- 可清理过期临时缓存，保留日程与识别模型。
