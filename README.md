# DDL Manager · 我的 DDL

**v4 · Windows 桌面待办、日程与截止日期管理工具**

把待办、课程、日程和截止时间集中到一个地方：用主页查看紧迫事项，用日历安排日期，用悬浮窗在桌面上随时查看进度。支持中文文字拆分、本地图片识别、完成统计和可选的 Microsoft To Do 同步。

## 下载与首次使用

在 [Releases 下载页面](https://github.com/J0ey2ou/ddl-manager/releases/latest) 下载 **`DDLManager-v4.0.0-Setup-x64.exe`**（推荐）。

> 请下载 Release 的 Setup 安装包或软件 ZIP 附件。GitHub 自动生成的 **Source code (zip)** / **Source code (tar.gz)** 不是可运行的软件安装包。

1. 双击 Setup 安装包，选择安装目录。**C 盘、D 盘、E 盘均可**，默认安装在当前用户的本地应用目录，无需管理员权限。
2. 安装程序内置微软 WebView2 完整离线安装器，缺少运行时时自动安装；完成后从桌面或开始菜单打开 DDL Manager。
3. 首次运行注册一个本地账号，随后开始添加事项。
4. 在“设置”中按需要启用悬浮窗、快捷键、开机启动或 Microsoft To Do 同步。

无需安装 Python、配置开发环境或申请 AI API。文字识别和中文 OCR 模型已随包提供。

已有 WebView2 的电脑也可下载 `DDLManager-v4.0.0-windows-x64.zip` 便携版，完整解压到任意可写目录后打开 `DDLManager.exe`。便携版不重复附带 WebView2，体积更小。

### 运行要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 2004 或更新版本 / Windows 11，64 位 x64；在 Windows 11 上验证 |
| 桌面组件 | Microsoft Edge WebView2 Runtime；Setup 包已内置离线安装器 |
| 存放位置 | C / D / E 等磁盘的可写目录；不要选择无写入权限的系统目录 |
| 网络 | 安装包下载完成后可离线安装；本地待办、日历、统计、识别及文件导入导出不需要联网；微软登录与 To Do 同步需要联网 |

Setup 包使用微软 [Evergreen 离线部署方案](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution#offline-deployment)，用户无需另外查找组件。运行时采用微软共享组件，卸载 DDL Manager 时会保留它。

请保留 `DDLManager.exe`、`_internal` 文件夹和 `fresh-install.flag`，不要只复制 EXE，也不要直接在 ZIP 内运行。

## 功能介绍

### 1. 主页：待办与逾期事项

- 设置事项标题、截止日期和时间、分类，也可创建子任务及每日／每周／每月重复事项。
- 通过“今晚、明天、周末、下周”快速填写常用时间。
- 按截止时间显示事项，以颜色、剩余时间和进度条提示紧迫程度。
- 主页同时显示**逾期且未完成的独立日程**，避免过去的安排被遗漏。
- 支持编辑、删除和完成；DDL 待办支持批量完成、删除及修改分类。
- 对逾期事项，`✓` 可补记按时完成，`!` 标记逾期完成，统计会保留区别。
- 子任务显示完成数量和进度，便于把大任务拆成小步骤。

### 2. 日历：三条预览与拖动改期

- 月历整合待办和日程，关联事项去重显示。
- 日期格默认等高，能完整显示 **3 条事项**；超过时点击“还有 N 项”展开，再点击收起。
- 按住事项拖到其他日期即可改期，保留原有时间。
- 拖动后原地更新，保持页面滚动位置。
- 支持分类筛选、切换月份及回到本月；点击待办编辑，点击日程进入对应日期。

### 3. 今日事项：时间轴与日程安排

- 按日期查看当天日程与到期待办。
- 时间轴展示当天安排；日程支持开始时间、结束时间和备注。
- 可以手动新增，或用“快速拆分今日事项”一次识别多条安排。
- 支持编辑、完成、恢复未完成和删除。

### 4. 文字、图片与课表识别

输入、粘贴中文文字，或选择、粘贴图片，先识别预览，再勾选加入。能够处理日期、常见时段、编号列表与共享日期，例如：

```text
明天下午完成三件事：1.整理资料；2.准备演示；3.检查清单
```

- 可以在预览中修改标题、日期时间及事项类型，不会未经确认直接加入。
- 文字规则和图片 OCR 在本机运行，**识别图片不上传云端**。
- 课表支持按学期第一周日期、星期、时段、周次预览和批量导入。
- 点击“加入勾选事项”后，下方列表立即更新，识别预览保留。

识别结果可能受图片清晰度、排版和文字表达影响，请在导入前核对日期、课程名称和时间。首次加载 OCR 模型可能需要等待几秒。

### 5. 桌面悬浮窗

- 在设置中开启，显示未完成事项，每页最多三条，支持翻页。
- 显示标题、剩余／逾期时间和进度条；`✓` 按时完成，`!` 逾期完成，`×` 删除。
- 拖动标题或文字区域移动窗口；`＋` 打开独立快速添加窗口。
- 靠**左侧、右侧或顶部**放置后，鼠标移开自动收起，点击细小呼出条恢复。
- 右键可呼出主界面、打开设置、从剪贴板添加日程或退出；操作其他窗口后菜单自动关闭。
- 支持置顶、大小和不透明度调整，滑块修改可实时预览。

### 6. 进度与完成统计

- 查看所选月份的制定数量、完成数量、完成率、准时率、逾期数量和效率评分。
- 支持年度月度对比、月份对比、分类统计及任务进度。
- 完成热力图按实际完成日期展示。
- 统计包含独立日程，并对与 DDL 关联的日程去重。

### 7. 撤回、托盘与个性化

- 当前运行会话中保留当前账号最近 30 次可撤回操作。
- 关闭到托盘不会清空撤回记录；真正退出后清空。
- 支持主题、紧迫度配色、名言和模块显示设置。
- 可选开机启动，默认关闭。
- 同一个 Windows 会话只运行一个程序实例，再次双击会唤回原窗口。

### 8. Microsoft To Do（可选）

在设置中主动登录微软账号后，可将本地事项**单向同步**到 Microsoft To Do，默认使用 `DDL Manager` 清单。支持手动同步及可选自动同步，显示账号、清单和云端确认状态，并用来源关联减少重复上传。

微软登录凭据只保留在本次运行中，退出后需重新授权。此功能需要联网，不影响其他功能的离线使用；未启用时不会自动同步。它不是双向同步，微软客户端的刷新速度由微软客户端决定。

### 9. 跨电脑同步：导出日程 / 导入日程

主页右下角、撤回按钮上方提供两个同风格按钮。首次使用会显示简短说明。

1. 在电脑 A 登录本地账号，点击 **导出日程**，保存生成的 `.ddl.json` 文档。
2. 用 U 盘或您选择的方式将该文件复制到电脑 B。
3. 电脑 B 安装本软件并登录自己的本地账号，点击 **导入日程**，选择文件。
4. 确认新增和匹配数量；有分类冲突时，逐项选择 **保留原有分类** 或 **采用导入分类**，再点击确认导入。

- 名称（忽略首尾空格）和日期相同的事项，同步文件中的完成状态和完成时间，包括按时完成、逾期完成及恢复未完成；保留本机已有事项的时间、备注和类型。
- 其余事项直接添加；本机独有事项保留。同名同日有多条时优先按类型及具体时间匹配，再按顺序逐条匹配，重复导入同一文件不会重复添加。
- 新增事项保留原文件中的日期、分类、备注、重复设置、历史记录及有效的父子关联。关联计划随 DDL 一同传递；本机父任务截止时间较早时，新子任务会作为独立任务保留。
- 导入前只是预览，取消不会修改数据。导入后立即更新主页，可使用 **撤回：导入日程** 撤销整次操作。
- 仅导出当前本地账号的日程，不包含账号密码、登录凭据、软件设置、缓存或其他账号数据。文件是可读 JSON，包含个人日程，请自行妥善保管；发布安装包不包含此文件。
- 文件同步由用户主动操作，不会自动在电脑之间联网同步。支持本软件格式版本 1，单个文件最大 10 MB、最多 10000 条事项及 10000 条关联计划。

## 默认快捷键

可在设置中修改；若与其他软件冲突，请换一组组合键。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + A` | 打开主页添加事项 |
| `Ctrl + Alt + C` | 打开日历 |
| `Ctrl + Alt + T` | 打开今日事项 |
| `Ctrl + Alt + D` | 主窗口显示／隐藏 |
| `Ctrl + Alt + V` | 从剪贴板打开独立快速识别窗口 |

剪贴板内容仅在主动使用识别入口时读取，核对预览后再加入事项。

## 关闭、后台与退出

- 主窗口右上角 `X`：隐藏到 Windows 托盘，程序继续运行。
- 双击托盘图标：恢复主窗口；图标可能位于右下角的展开箭头中。
- 右键托盘 → **退出程序**：完全退出。
- 退出登录：切换本地账号，不等于退出程序。

## 全新安装、数据和更新

发布安装包与 ZIP 均由干净的程序构建产物生成，**不包含作者的账号、任务、日程、数据库、导出文件、浏览器缓存或登录记录**。

```text
DDLManager/
├─ DDLManager.exe       程序
├─ _internal/           运行依赖、界面资源及离线 OCR 模型
├─ fresh-install.flag   阻止首次启动导入电脑上的旧数据库
├─ 使用说明.txt         简明入门说明
└─ README.md            本文档
```

运行后才会在程序旁创建你自己的 `data` 文件夹。安装版默认位置为 `%LOCALAPPDATA%\Programs\DDLManager\data`；便携版位于解压目录内。账号、事项、设置及缓存存放在本机；跨电脑可使用主页的导出日程／导入日程功能。

**备份：**先从托盘完全退出，再备份整个 `data` 文件夹。恢复时也先退出程序，再放回数据。

**更新：**先退出并备份 `data`，安装新版到原目录；便携版用新版 EXE 和 `_internal` 更新程序文件，保留原来的 `data`。卸载程序会保留生成的使用数据，方便恢复。

**再次分享：**发送原始 Setup 或 ZIP 文件。不要压缩自己使用后的整个软件目录，否则会把自己的 `data` 一起带上。

## 常见问题

**下载的压缩包里为什么没有 EXE？** 可能下载了 GitHub 自动生成的源码压缩包。请下载 Releases 中名为 `DDLManager-v4.0.0-windows-x64.zip` 的附件。

**双击后没有正常显示窗口？** 先查看托盘中是否已经运行。便携版请检查是否完整解压、保留 `_internal`、具备 WebView2，以及目录是否可写；缺组件时可改用 Setup 包安装。

**只有 C 盘可以使用吗？** 可以，默认安装位置就在当前 Windows 用户的 C 盘本地目录（以系统设置为准）。当前发布包面向 Windows x64，不提供 macOS 或 Linux 版本。

**是否需要付费 AI 接口？** 不需要，本地文字规则和 OCR 模型随程序提供。

**为什么关闭窗口后还在运行？** 主窗口关闭会隐藏到托盘；请用托盘菜单的“退出程序”完全退出。

**新下载的软件会出现作者的数据吗？** 不会。发布包不含使用数据，并带有阻止导入旧数据库的 `fresh-install.flag`，首次使用需自行注册。

**如何反馈问题？** 可在本仓库的 Issues 中描述操作步骤、预期结果、实际结果和 Windows 版本。截图前请遮挡自己的日程、账号和其他私人内容。
