# 时光分享：可选旅人插画

本补丁让宣传片中的同一角色出现在软件实际导出的海报中。增加第四个可选人物“旅人”，沿用原有统计、隐私控制和三个版式，保留默认人物。没有数据库迁移，也没有摄像头或手势控制功能。

当前 GitHub 主分支是发布说明仓库，没有桌面端 Python 源文件。因此本目录保存精确补丁、原创插画和测试，供桌面源码工程应用；它不是已发布的安装程序，也不会自动更新 v5.1.1。

在已有 v5.1.1 桌面源码根目录应用 traveler.patch，将 traveler.png 放入 static/share-art/，将测试放入 tests/。新增人物由影片同一分层角色渲染，图像生成工具仅用于原创部件绘制。

验证：6 项海报测试通过，覆盖三尺寸 PNG、未知人物拒绝、隐藏名称不改变像素、既有隐私统计。浏览器实际选择旅人并导出周、月、年 PNG；全部测试使用隔离数据库，没有访问用户生产数据库。

测试命令：python -m unittest tests.test_share_traveler tests.test_time_share
