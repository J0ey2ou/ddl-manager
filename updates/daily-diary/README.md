# 今日日记

右侧「常用工具 → 今日日记」打开今天的记录。月历中的「写日记」表示当天还没有记录，「看日记」可以查看和编辑已保存的内容。点击日期进入日视图后，「当天日记」打开同一篇记录。

每个本地账号每天保存一篇日记。首次使用新版源码启动应用时会自动建表。正文保存在本地 SQLite 数据库，包含在完整备份中。两个窗口同时编辑时，旧版本的保存请求会提示冲突，并保留输入框中的文字。

## 应用补丁

本次以源码补丁交付。将本目录的 `daily-diary.patch` 放入已有的 v5.1.1 桌面应用源码根目录，在该目录执行以下命令：

```sh
git apply --check daily-diary.patch
git apply daily-diary.patch
python -m unittest discover -s tests -p test_diary.py
```

重新启动源码版即可使用。补丁包含数据库结构、后端接口、界面和回归测试。
